Це завдання допоможе тобі опанувати розгортання віртуальних машин у хмарних платформах. Ця навичка знадобиться в подальшій кар'єрі: більшість компаній переходять у хмару, щоб зробити свою роботу безпечнішою та ефективнішою.

Сьогодні ти навчишся створювати й налаштовувати віртуальну машину в Amazon Web Services: обирати тип екземпляра, образ ОС та інші параметри.

Завдання (крок за кроком)

Нижче наведено скорочений опис кроків. Повну інструкцію зі скриншотами дивись у лабораторній роботі до цього модуля.

Створення та запуск віртуальної машини на AWS

  1. Перейди в AWS Console і створи обліковий запис, якщо його ще немає.
  2. У консолі AWS вибери Launch a virtual machine (Запустити віртуальну машину).
  3. Вибери образ машини Amazon (AMI), тип екземпляра, розмір сховища та інші параметри.
  4. Підключись до екземпляра. Для Windows-екземпляра отримай пароль на вкладці RDP client за допомогою пари ключів і завантаж RDP-файл.
Обирай параметри з позначкою Free tier eligible, а для правила RDP у групі безпеки — My IP замість Anywhere. Після того як зробиш скриншот для здачі, обов'язково видали екземпляр (Instance state → Terminate instance), щоб не отримати неочікуваний рахунок.

Критерії прийняття завдання

  1. Віртуальну машину створено на AWS: вибрано образ машини, тип екземпляра, розмір сховища та інші необхідні параметри.

Формат здачі

Скриншот з AWS Console, який підтверджує успішний запуск віртуальної машини AWS з Windows.
