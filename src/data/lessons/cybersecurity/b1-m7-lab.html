Використання OpenSSL

У цій лабораторній роботі ти встановиш OpenSSL, навчишся створювати ключі та запити на підписання сертифіката (CSR), а потім зашифруєш і розшифруєш повідомлення. Спершу встанови OpenSSL для своєї операційної системи.

Linux: перевірка встановлення

У більшості дистрибутивів Linux OpenSSL уже встановлений. Перевір це командою, що відповідає твоєму типу пакетів.

Дистрибутиви з rpm-пакетами (Fedora, RHEL, Rocky):

rpm -qa | grep -i openssl

Дистрибутиви з deb-пакетами (Debian, Ubuntu):

dpkg -l | grep -i openssl

Arch Linux:

pacman -Q openssl

Windows: встановлення

Завантаж OpenSSL зі списку офіційних збірок. Запусти інсталятор (обери 64-розрядну збірку Win64 OpenSSL) і встанови програму.

Потім відкрий PowerShell і перейди в каталог встановлення (зазвичай C:\Program Files\OpenSSL-Win64\bin\). Виконуй команди OpenSSL звідти або додай цей каталог до змінної середовища PATH, щоб запускати openssl з будь-якого місця.

macOS: встановлення

Спосіб 1. Через Homebrew

1. Встанови Homebrew. Відкрий Термінал (він у папці «Утиліти», або знайди його через Spotlight) і виконай команду:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Дотримуйся інструкцій у терміналі, щоб завершити встановлення.

2. Встанови OpenSSL:

brew install openssl

3. Перевір встановлення:

openssl version
У macOS команда openssl може запускати вбудовану в систему бібліотеку LibreSSL, а не встановлений OpenSSL. Щоб запустити саме його, виконай: $(brew --prefix openssl)/bin/openssl version.

Спосіб 2. Через MacPorts

1. Встанови MacPorts за інструкцією з офіційного сайту MacPorts.

2. Відкрий Термінал і встанови OpenSSL. Система попросить пароль адміністратора:

sudo port install openssl

3. Перевір встановлення:

openssl version

Якщо команда показує LibreSSL, запусти встановлену версію за повним шляхом: /opt/local/bin/openssl version.

Основні команди OpenSSL

Перевірка версії

openssl version -a

Команда покаже версію OpenSSL, дату збірки та шлях до каталогу з налаштуваннями.

Генерація закритого ключа

Спершу створи закритий (приватний) ключ RSA довжиною 2048 біт:

openssl genrsa -out yourdomain.key 2048

Перегляд закритого ключа

cat yourdomain.key
-----BEGIN PRIVATE KEY-----
MIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcwggSjAgEAAoIBAQ...
...
-----END PRIVATE KEY-----
Це навчальний ключ. Справжній закритий ключ ніколи не показують на екрані під час демонстрацій, не надсилають у чатах і не додають у Git.

Створення CSR

CSR (Certificate Signing Request, запит на підписання сертифіката) — файл, який надсилають центру сертифікації, щоб отримати сертифікат. Створи його за допомогою закритого ключа:

openssl req -new -key yourdomain.key -out yourdomain.csr

OpenSSL запитає дані про організацію: країну, регіон, місто, назву компанії, підрозділ і доменне ім'я (Common Name). Ці дані можна передати одразу в командному рядку за допомогою параметра -subj:

openssl req -new -key yourdomain.key -out yourdomain.csr -subj "/C=US/ST=CA/L=San Francisco/O=Your Company, Inc./OU=IT/CN=yourdomain.com"

Перегляд параметрів закритого ключа

openssl rsa -text -in yourdomain.key -noout

Команда покаже довжину ключа (Private-Key: (2048 bit, 2 primes)) і його математичні складові: модуль, експоненти та прості числа.

Отримання відкритого ключа

Відкритий ключ обчислюється із закритого:

openssl rsa -in yourdomain.key -pubout -out yourdomain_public.key

Закритий ключ і CSR однією командою

openssl req -new -newkey rsa:2048 -nodes -keyout yourdomain.key -out yourdomain.csr -subj "/C=US/ST=CA/L=San Francisco/O=Your Company, Inc./OU=IT/CN=yourdomain.com"

Параметр -nodes означає, що закритий ключ не буде захищено паролем.

Перевірка CSR

openssl req -text -in yourdomain.csr -noout -verify
Certificate request self-signature verify OK
Certificate Request:
    Data:
        ...
        Subject: C=US, ST=CA, L=San Francisco, O=Your Company, Inc., OU=IT, CN=yourdomain.com

Тепер ти знаєш, як за допомогою OpenSSL генерувати ключі та запити на сертифікати.

Завдання: генерація ключа та шифрування повідомлення

1. Завантаж і встанови OpenSSL — через Homebrew чи MacPorts на macOS або іншим способом для твоєї операційної системи (див. вище).

2. Відкрий термінал або командний рядок.

3. Згенеруй новий ключ RSA:

openssl genrsa -out private_key.pem 2048

4. Перевір створений ключ:

openssl rsa -in private_key.pem -text -noout

5. Згенеруй відкритий ключ:

openssl rsa -in private_key.pem -outform PEM -pubout -out public_key.pem

6. Створи текстовий файл plaintext.txt з будь-яким вмістом, наприклад «Some secret message»:

echo "Some secret message" > plaintext.txt

7. Зашифруй повідомлення відкритим ключем:

openssl pkeyutl -encrypt -inkey public_key.pem -pubin -in plaintext.txt -out encrypted.txt

Спробуй переглянути encrypted.txt командою cat: замість тексту ти побачиш нечитабельний набір символів.

8. Розшифруй повідомлення закритим ключем:

openssl pkeyutl -decrypt -inkey private_key.pem -in encrypted.txt -out decrypted.txt

9. Перевір, чи збігається розшифроване повідомлення з оригіналом:

diff plaintext.txt decrypted.txt
cat decrypted.txt

Якщо diff нічого не виводить, файли однакові. Команда cat покаже текст «Some secret message».

Готово! Ти згенерував ключі, зашифрував і розшифрував повідомлення за допомогою OpenSSL.
