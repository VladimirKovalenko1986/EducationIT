Переходимо до виконання домашнього завдання!

Завдання складається з двох частин. Спершу опишеш загрози для мобільного пристрою й перевіриш його налаштування безпеки, а потім перевіриш безпеку IoT- чи іншого пристрою, яким користуєшся.

Воно допоможе тобі:

  • усвідомити загрози для мобільних та IoT-пристроїв;
  • отримати практичний досвід перевірки налаштувань безпеки.

Частина 1. Мобільні пристрої

Крок 1. Основні загрози

  • Опиши основні загрози, з якими стикаються мобільні пристрої.
  • Які види ПЗ використовують для атак? Наведи приклади.
  • Які можливі шляхи вторгнення в приватні дані користувача?

Крок 2. Заходи безпеки

  • Які основні заходи захищають мобільний пристрій від загроз?
  • Які типи паролів найнадійніші для захисту доступу й чому?

Крок 3. Налаштуй безпеку пристрою

Наприклад:

  • встанови складний пароль або біометрію (відбиток пальця, розпізнавання обличчя);
  • увімкни шифрування даних на пристрої;
  • налаштуй дозволи додатків і сервісів.

Крок 4.

Напиши, що саме зробив для покращення безпеки.

Частина 2. IoT-пристрої

Крок 1.

Обери один підключений IoT-пристрій (смарт-термостат, вебкамера, розумне освітлення тощо).

Крок 2.

Виконай один або кілька заходів безпеки:

  • зміни пароль застосунку чи вебпанелі керування;
  • увімкни двофакторну автентифікацію;
  • перевір наявність оновлень ПЗ і встанови їх.

Крок 3.

Напиши, що саме зробив для покращення безпеки.

Немає IoT-пристрою? Виконай цю частину для будь-якого пристрою з повсякденного життя — комп'ютера, смартфона чи телевізора: зміни пароль входу, встанови й онови антивірус, увімкни PIN/біометрію, перевір і встанови оновлення ОС. Потім так само опиши, що зробив.
