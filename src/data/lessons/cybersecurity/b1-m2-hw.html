Створи концепцію SOC

Пропонуємо тобі створити концепцію SOC для будь-якої організації на твій вибір.

Отже, сьогодні ти:

  • проаналізуєш потреби обраної тобою організації;
  • розробиш загальний план дій, який описує функції та завдання SOC;
  • опишеш функції та відповідальності для кожної зазначеної ролі в SOC.

Рекомендація

Перш ніж розпочати, розглянь реальні приклади SOC, їхні функції та організаційну структуру:

  • IBM X-Force Command Center (XFCC): XFCC є центром безпеки, розташованим у Кембриджі, Массачусетс, і є частиною глобальної мережі IBM Security Operations Centers (SOCs). Він надає послуги моніторингу безпеки, аналізу подій, виявлення загроз та реагування на інциденти для клієнтів IBM по всьому світу.
  • Google Security Operations Center (Google SOC): Google SOC гарантує безпеку всіх продуктів та послуг Google, зокрема Gmail, Google Drive, Google Cloud Platform тощо. Він використовує передові технології моніторингу, аналізу великих даних та штучного інтелекту для виявлення та реагування на загрози.
  • Amazon Web Services (AWS) Security Operations Center (AWS SOC): AWS SOC гарантує безпеку облікових записів та послуг AWS для мільйонів клієнтів по всьому світу. Він використовує автоматизовані системи моніторингу та аналізу, щоб виявляти аномальну активність та втручатися в реальному часі.
  • Microsoft Cyber Defense Operations Center (CDOC): CDOC є центром безпеки Microsoft, який надає обслуговування для всіх продуктів та послуг компанії, таких як Windows, Office 365, Azure тощо. Він використовує інтегровані аналітичні платформи та спеціалізовані команди експертів для виявлення, аналізу та реагування на кіберзагрози.

Для отримання додаткової інформації про ці компанії та їхні центри безпеки ти можеш скористатися наступними посиланнями:

  • IBM X-Force Cyber Range: дізнайся більше про IBM X-Force Cyber Range та послуги, які вони надають, на цьому сайті. Брошуру X-Force Command від IBM з детальною інформацією про цей центр безпеки можна завантажити тут.
  • Google Security Operations Center (Google SOC): дізнайся більше про Google SOC та його функції на офіційному вебсайті Google Cloud.
  • Amazon Web Services (AWS) Security Operations Center (AWS SOC): ознайомся з AWS SOC та його послугами на вебсайті Amazon Web Services.
  • Microsoft Cyber Defense Operations Center (CDOC): детальніше про CDOC та його роботу можна знайти на офіційному сайті Microsoft Security.

Завдання (крок за кроком)

  1. Проведи аналіз потреб вибраної організації щодо безпеки та визнач основні цілі SOC.
  2. Розроби загальний план дій, який описує функції та завдання SOC для вибраної організації.
  3. Для кожної ролі в SOC напиши короткий опис її функцій та відповідальностей. Наприклад:
    • Аналізатор подій: відповідає за моніторинг, аналіз та виявлення потенційно шкідливих подій в мережі або системах.
    • Інцидент-менеджер: відповідає за керування інцидентами та реагування на виявлені загрози.
    • Аналітик безпеки: проводить детальний аналіз виявлених загроз та розробляє стратегії захисту.
    • Керівник SOC: відповідає за загальне керівництво та координацію роботи SOC.

Формат здачі

Документ на Google Docs з розшареним доступом.

Критерії прийняття завдання

  • Визначено конкретні загрози та вразливості, які становлять потенційні ризики для організації.
  • Ідентифіковано основні цілі безпеки, яких має досягти SOC.
  • Чітко сформульовані функції та завдання SOC, що відображають основні потреби безпеки організації.
  • Описано ролі, відповідальні за кожну функцію SOC, і зазначено відповідні навички та компетенції для кожної ролі.
