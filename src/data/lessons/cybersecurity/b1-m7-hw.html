Настав час практики!

Сьогодні ми розглянемо використання OpenSSL для генерації ключа та шифрування повідомлення.

Навички, які отримаєш:

  • робота з OpenSSL для забезпечення безпеки даних;
  • генерація RSA-ключів;
  • шифрування та розшифрування повідомлень.

Завдання (крок за кроком)

1. Завантаж і встанови OpenSSL на свій комп'ютер будь-яким зручним способом: через Homebrew або MacPorts на macOS чи іншим доступним для твоєї операційної системи. Інструкції є в лабораторній роботі.

2. Відкрий термінал або командний рядок.

3. Згенеруй новий RSA-ключ:

openssl genrsa -out private_key.pem 2048

4. Перевір створений ключ:

openssl rsa -in private_key.pem -text -noout

5. Згенеруй відкритий ключ:

openssl rsa -in private_key.pem -outform PEM -pubout -out public_key.pem

6. Створи текстовий файл plaintext.txt з будь-яким вмістом, наприклад «Some secret message»:

echo "Some secret message" > plaintext.txt

7. Зашифруй повідомлення відкритим ключем:

openssl pkeyutl -encrypt -inkey public_key.pem -pubin -in plaintext.txt -out encrypted.txt

8. Розшифруй повідомлення закритим ключем:

openssl pkeyutl -decrypt -inkey private_key.pem -in encrypted.txt -out decrypted.txt

9. Перевір, чи збігається розшифроване повідомлення з оригіналом:

diff plaintext.txt decrypted.txt
cat decrypted.txt

Якщо diff нічого не виводить, файли однакові.

Формат здачі

Документ на Google Docs із розшареним доступом, у якому є скриншоти кожного кроку процесу.

Критерії прийняття завдання

  1. Усі кроки виконано правильно.
  2. Для кожного кроку є скриншот.
  3. Розшифроване повідомлення збігається з оригінальним текстом.
