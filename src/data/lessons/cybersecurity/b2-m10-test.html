Як діє SQL-ін'єкція?

  • Впровадження зловмисного коду в інші програми
  • Вставка шкідливого коду у запити до бази даних
  • Використання соціальних мереж для атак

Що таке XSS у контексті кібербезпеки?

  • Переповнення буфера
  • Впровадження шкідливих скриптів на вебсайти
  • Атаки на мережеві пристрої

Що таке переповнення буфера?

  • Заповнення пам'яті даними так, що їх розмір перевищує ліміти
  • Зміна налаштувань брандмауера
  • Розробка бекдорів для систем

Яка роль соціальної інженерії в атаках?

  • Використання скриптів для атак
  • Маніпулювання людьми для отримання конфіденційної інформації
  • Введення команд у командний інтерпретатор системи

Що означає «відповідальне розкриття інформації» (responsible disclosure)?

  • Розкриття конфіденційної інформації зловмисникам
  • Практика повідомлення власників систем про виявлені вразливості
  • Захоплення контролю над браузером користувача

Які загрози можуть виникнути для мобільних пристроїв?

  • Віруси та шкідливе ПЗ
  • Фішингові атаки
  • Втрата або крадіжка пристрою
  • Усі відповіді правильні

Які загрози можуть виникнути для IoT-пристроїв?

  • Вразливості в програмному забезпеченні
  • Недостатнє шифрування даних
  • Відсутність оновлень ПЗ
  • Усі відповіді правильні

Що таке фішингова атака?

  • Атака, спрямована на отримання конфіденційної інформації
  • Атака, яка використовує віруси для злому пристрою
  • Атака, яка перешкоджає роботі бездротової мережі
  • Усі відповіді неправильні

Що таке антивірусне програмне забезпечення?

  • Програма, яка захищає пристрій від спливаючих вікон
  • Програма, яка виявляє та видаляє шкідливе ПЗ
  • Програма, яка оптимізує роботу пристрою
  • Усі відповіді правильні

Які методи автентифікації можна використати для захисту мобільних пристроїв?

  • Введення пароля
  • Використання відбитка пальця
  • Розпізнавання обличчя
  • Усі перелічені методи

Який поштовий протокол клієнт використовує лише для надсилання листів на сервер, але ніколи для отримання?

  • POP3
  • SMTP

  • WINS

Віртуальні машини зазвичай не піддаються такому самому впливу шкідливого ПЗ, що й фізичні.

Який хакер використовує знання, щоб вторгатися в приватність інших, порушуючи закони й знижуючи рівень безпеки систем?

  • Сірий хакер
  • Чорний хакер
  • Білий хакер

Ти використовуєш Facebook, Twitter та інші соцмережі для збору інформації про ціль. Який метод тут застосовується?

  • Соціальна інженерія (розвідка)

Яку техніку ти використаєш, щоб визначити активні служби на цілі та можливі точки входу?

  • Ping

  • Захоплення банерів (Banner grabbing)

  • NIST

Що таке система виявлення вторгнень (IDS)?

  • Система, яка виявляє атаки чи підозрілу активність у мережі або системі
  • Система для автоматичного видалення вірусів
  • Інструмент для збереження паролів користувача
  • Програма для блокування небажаних листів

Яке завдання виконує файрвол у мережевій безпеці?

  • Контроль і фільтрація мережевого трафіку згідно з правилами безпеки
  • Захист від комп'ютерних вірусів
  • Моніторинг швидкості інтернет-з'єднання
  • Захист від перехоплення паролів користувача

У чому полягає принцип найменших привілеїв?

  • Кожен користувач має доступ до всіх ресурсів мережі
  • Доступ користувача обмежений лише необхідними ресурсами для його обов'язків
  • Для всіх користувачів дозволено однакові паролі
  • Адміністратори мають повний доступ до всіх ресурсів

  • FTP
  • HTTPS
  • DNS

  • Використання підступних методів для отримання пароля
  • Використання соціальної інженерії для перехоплення пароля
  • Атака, що використовує шкідливі програми для доступу до системи
