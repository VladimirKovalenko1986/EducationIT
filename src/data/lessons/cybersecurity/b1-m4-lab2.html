Налаштування OpenVPN

1. Перейди в домашній каталог:

cd

2. Клонуй репозиторій OpenVPN:

git clone https://github.com/OpenVPN/openvpn

Якщо в консолі з'явилось повідомлення, що команду git не знайдено (git: command not found), встанови git:

sudo apt install git

І повтори клонування репозиторію:

git clone https://github.com/OpenVPN/openvpn

3. Скопіюй server.conf до директорії OpenVPN. Заміни ВАШ_КОРИСТУВАЧ на свого користувача:

sudo cp /home/ВАШ_КОРИСТУВАЧ/openvpn/sample/sample-config-files/server.conf /etc/openvpn/server/

4. Відкрий цей файл для редагування. Пересуватися файлом можна стрілками вгору та вниз, а шукати текст у nano — комбінацією Ctrl + W.

sudo nano /etc/openvpn/server/server.conf

5. Знайди рядок ;data-ciphers AES-256-GCM:AES-128-GCM:?CHACHA20-POLY1305:AES-256-CBC, закоментуй його символом # та додай рядки:

cipher AES-256-GCM
auth SHA256

6. Знайди рядок dh dh2048.pem або dh dh.pem і закоментуй його: у нашому випадку файл Діффі-Геллмана не потрібен. Після закоментованого рядка встав:

dh none

7. Щоб OpenVPN працював без зайвих привілеїв, знайди рядки ;user openvpn та ;group openvpn. Зроби з них такі рядки. Важливо прибрати символи ; на початку:

user nobody
group nogroup

8. У довільне місце файлу додай рядок. Саме він спрямовує весь трафік клієнта через VPN:

push "redirect-gateway def1"

9. Знайди рядок tls-auth ta.key 0, закоментуй його та додай рядок із tls-crypt, як на скриншоті нижче. Усі інші варіанти авторизації закоментуй. Важливо: у новому рядку не повинно бути 0 після ta.key.

tls-crypt ta.key # This file is secret

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X, щоб закрити редактор.

Конфігурація мережі на сервері VPN

Щоб VPN-сервер міг пересилати трафік клієнтів, потрібно змінити конфігурацію мережі.

1. Відкрий конфігураційний файл /etc/sysctl.conf:

sudo nano /etc/sysctl.conf

2. Розкоментуй рядок net.ipv4.ip_forward=1:

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X.

3. Застосуй нові налаштування:

sudo sysctl -p

Налаштування мережевого екрана

1. Щоб визначити відкритий мережевий інтерфейс, виконай команду:

ip route list default

Якщо твій інтерфейс не eth0, підстав його назву замість eth0 у правилі нижче.

2. Відкрий файл /etc/ufw/before.rules:

sudo nano /etc/ufw/before.rules

На початок файлу встав такий текст:

# START OPENVPN RULES
# NAT table rules
*nat
:POSTROUTING ACCEPT [0:0]
-A POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE
COMMIT
#END OPENVPN RULES

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X.

3. Відкрий файл /etc/default/ufw:

sudo nano /etc/default/ufw
Важливо! Цей файл не повинен бути порожнім. Якщо він порожній, встанови ufw командою sudo apt install ufw і повтори налаштування мережевого екрана спочатку.

4. У рядку DEFAULT_FORWARD_POLICY зміни значення DROP на ACCEPT:

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X.

5. Відкрий UDP-трафік на порту 1194 і дозволь OpenSSH:

sudo ufw allow 1194/udp
sudo ufw allow OpenSSH
Не пропускай правило для OpenSSH. Без нього після ввімкнення мережевого екрана ти втратиш SSH-доступ до віртуальної машини.

6. Перезапусти UFW. Під час виконання другої команди потрібно ввести y:

sudo ufw disable
sudo ufw enable

Запуск OpenVPN

1. Запусти службу OpenVPN і додай її в автозавантаження:

sudo systemctl -f enable openvpn-server@server.service
sudo systemctl start openvpn-server@server.service

2. Перевір, чи служба запустилась коректно:

sudo systemctl status openvpn-server@server.service

Натисни q, щоб повернутися до командного рядка.

Створення користувача

1. Створи структуру директорій, де зберігатимуться файли:

mkdir -p ~/clients/files

2. Скопіюй шаблон конфігурації клієнта в папку clients. Заміни ВАШ_КОРИСТУВАЧ на свого користувача:

sudo cp /home/ВАШ_КОРИСТУВАЧ/openvpn/sample/sample-config-files/client.conf ~/clients/base.conf

3. Відкрий base.conf:

sudo nano ~/clients/base.conf

4. Знайди рядки з user та group і зроби їх такими, прибравши символ ; на початку:

user nobody
group nogroup

5. У рядку remote my-server-1 1194 заміни my-server-1 на IP-адресу твоєї ВМ.

6. Закоментуй такі рядки:

# ca ca.crt
# cert client.crt
# key client.key

7. У довільне місце додай рядок:

key-direction 1

8. Закоментуй рядок ;tls-auth ta.key 1 і додай рядок із tls-crypt, як на скриншоті нижче. Усі інші варіанти авторизації закоментуй.

tls-crypt ta.key

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X.

9. Створи скрипт make_config.sh. Він збиратиме конфігурацію клієнта й зберігатиме її в директорії ~/clients/files:

sudo nano ~/clients/make_config.sh

10. Встав у файл наведений нижче текст. Важливо, щоб між рядками не було порожніх рядків. Заміни ВАШ_КОРИСТУВАЧ на свого користувача тричі:

#!/bin/bash
# First argument: Client identifier
KEY_DIR=/home/ВАШ_КОРИСТУВАЧ/clients/keys
OUTPUT_DIR=/home/ВАШ_КОРИСТУВАЧ/clients/files
BASE_CONFIG=/home/ВАШ_КОРИСТУВАЧ/clients/base.conf
cat ${BASE_CONFIG} \
<(echo -e '<ca>') \
${KEY_DIR}/ca.crt \
<(echo -e '</ca>\n<cert>') \
${KEY_DIR}/${1}.crt \
<(echo -e '</cert>\n<key>') \
${KEY_DIR}/${1}.key \
<(echo -e '</key>\n<tls-crypt>') \
${KEY_DIR}/ta.key \
<(echo -e '</tls-crypt>') \
> ${OUTPUT_DIR}/${1}.ovpn

Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X.

11. Признач скрипту відповідні права:

sudo chmod 700 ~/clients/make_config.sh

Створення конфігураційного файлу для клієнта

1. Сертифікат клієнта client-1.crt та ключ client-1.key уже створено. Тепер запусти скрипт, щоб отримати файл конфігурації клієнта:

cd ~/clients
sudo ./make_config.sh client-1

У результаті скрипт створить файл ~/clients/files/client-1.ovpn.

Файл .ovpn містить приватний ключ клієнта, тому поводься з ним як із паролем. Той, хто його отримає, зможе підключитися до твого VPN.

2. Завантаж на свій особистий ПК VPN-клієнт з офіційного сайту OpenVPN.

3. Щоб завантажити конфігураційні файли на свій ПК, скористаємося утилітою WinSCP. Завантаж її з офіційного сайту WinSCP.

4. Підключись за допомогою WinSCP до своєї ВМ:

Введи дані для підключення: IP-адресу своєї ВМ, порт 22, логін і пароль. Протокол — SFTP.

Перевірка

Щоб переконатися, що весь трафік проходить через VPN-тунель, перевір зовнішню IP-адресу (WAN IP) свого ПК на сайті whatismyipaddress.com.

Якщо все налаштовано правильно, ти побачиш IP-адресу своєї віртуальної машини.
