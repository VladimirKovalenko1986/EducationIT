Ця лабораторна робота використовує віртуальні машини на платформі Microsoft Azure. Щоб отримати доступ до ВМ, звернись до свого клієнт-менеджера.

Зверни увагу, що під час роботи з Azure віртуальні машини можуть бути тимчасово недоступними. Причини можуть бути такі:

  • Технічне обслуговування. Azure регулярно проводить планові роботи для стабільної та безпечної роботи своїх сервісів.
  • Перезавантаження серверів. Іноді серверам, на яких працюють віртуальні машини, потрібно перезавантажитися, щоб застосувати оновлення або виправити помилки.
  • Неполадки в апаратному забезпеченні. Можуть виникати проблеми з фізичним обладнанням, на якому працюють віртуальні машини.
  • Оновлення безпеки. Важливі оновлення можуть вимагати тимчасового відключення машин.

Ми розуміємо, що це може спричиняти дискомфорт і затримки в навчанні. Тому просимо якомога швидше повідомляти про будь-які проблеми, щоб ми могли оперативно їх вирішити.

Налаштування OpenVPN для перенаправлення трафіку через VPN

Огляд

У цій лабораторній роботі ми налаштуємо сервер OpenVPN так, щоб весь мережевий трафік проходив через VPN-тунель. Це дозволить створити безпечне та приватне з'єднання з інтернетом. Роботу виконуємо в ОС Linux.

Для зручності центр сертифікації та VPN-сервер у цій лабораторній працюють на одній машині, тому команди scp копіюють файли локально. У реальному середовищі ЦС розміщують на окремому, добре захищеному сервері, а файли передають між машинами.

Підключення до віртуальної машини за допомогою PuTTY

1. Завантаж та встанови програму PuTTY з офіційного сайту PuTTY.

2. Запусти програму PuTTY.

3. У розділі Session введи IP-адресу або доменне ім'я віртуальної машини. Порт SSH за замовчуванням — 22.

4. Натисни кнопку Open, щоб встановити з'єднання.

5. У вікні, що відкриється, введи ім'я користувача та пароль. Щоб уникнути помилок, логін і пароль краще скопіювати: виділи текст, натисни Ctrl + C і встав його правою кнопкою миші у вікні PuTTY.

6. Пароль, на відміну від логіна, у PuTTY не відображається. Просто введи або встав його й натисни Enter.

Після успішного входу ти отримаєш доступ до командного рядка віртуальної машини.

У macOS та Linux PuTTY не потрібен. Підключись із термінала командою ssh ім'я_користувача@IP-адреса.

Центр сертифікації

Розгортання VPN-сервера слід розпочати з налаштування центру сертифікації (ЦС). Він використовуватиметься виключно для створення, підписання та відкликання сертифікатів.

1. Встанови утиліту easy-rsa:

sudo apt update
sudo apt install easy-rsa

Підтвердь встановлення: введи y і натисни Enter.

2. Створи каталог ~/easy-rsa:

mkdir ~/easy-rsa

3. Створи посилання на файли easy-rsa:

ln -s /usr/share/easy-rsa/* ~/easy-rsa/

4. Встанови права доступу, щоб каталог був доступний лише тобі:

chmod 700 ~/easy-rsa

5. Запусти скрипт easyrsa:

cd ~/easy-rsa
./easyrsa init-pki

Так створюється директорія інфраструктури відкритих ключів (Public Key Infrastructure, PKI).

6. Тепер потрібно підготувати параметри для секретного ключа й сертифіката. Створи файл vars у каталозі ~/easy-rsa:

sudo nano ~/easy-rsa/vars

Якщо редактор не відкрився, а в консолі з'явилося повідомлення sudo: nano: command not found:

тоді встанови редактор nano:

sudo apt install nano

Після цього повтори команду для створення файлу vars:

sudo nano ~/easy-rsa/vars

7. Коли редактор відкриється, скопіюй у файл такий текст:

set_var EASYRSA_REQ_COUNTRY    "UA"
set_var EASYRSA_REQ_PROVINCE   "Kyiv"
set_var EASYRSA_REQ_CITY       "Kyiv City"
set_var EASYRSA_REQ_ORG        "Test Company"
set_var EASYRSA_REQ_EMAIL      "your_address@gmail.com"
set_var EASYRSA_REQ_OU         "LDP"
set_var EASYRSA_ALGO           "ec"
set_var EASYRSA_DIGEST         "sha512"

Слідкуй, щоб між рядками не було порожніх рядків. Перед виходом збережи файл: натисни Ctrl + S, а потім Ctrl + X, щоб закрити редактор.

8. Запусти скрипт easyrsa:

./easyrsa build-ca

Тут потрібно придумати парольну фразу. Її доведеться вводити для доступу до ЦС під час операцій із сертифікатами. Радимо просто ввести pass і натиснути Enter.

pass
У лабораторній пароль простий для зручності. У реальному середовищі використовуй довгу складну парольну фразу.

Пароль під час введення не відображається. Підтвердь його: введи ще раз і натисни Enter.

pass

Система запропонує ввести Common Name — ім'я твого ЦС. Прийми ім'я за замовчуванням, натиснувши Enter.

Файл ca.crt — це сертифікат ЦС, який містить його відкритий ключ. Клієнти та сервери використовуватимуть його для перевірки сертифікатів.

Тепер твій центр сертифікації готовий до роботи.

OpenVPN і Easy-RSA

1. Встанови власника та права для папки ~/easy-rsa. Заміни ВАШ_КОРИСТУВАЧ на свого користувача, наприклад user036:

sudo chown ВАШ_КОРИСТУВАЧ ~/easy-rsa
chmod 700 ~/easy-rsa

Сертифікат та закритий ключ OpenVPN

Тепер усе необхідне для генерації закритих ключів і запитів на підписання сертифікатів встановлено на сервері VPN.

1. Створимо секретний ключ і запит на підпис сертифіката. Перейди до директорії ~/easy-rsa:

cd ~/easy-rsa

2. Запусти easyrsa, де server — це Common Name (CN) твого VPN-сервера:

./easyrsa gen-req server nopass

Система запропонує ввести Common Name. Прийми ім'я за замовчуванням, натиснувши Enter.

3. Скопіюй секретний ключ server.key до /etc/openvpn/server. Заміни ВАШ_КОРИСТУВАЧ на свого користувача:

sudo mkdir /etc/openvpn
sudo mkdir /etc/openvpn/server
sudo cp /home/ВАШ_КОРИСТУВАЧ/easy-rsa/pki/private/server.key /etc/openvpn/server/

Підписання запиту сертифіката

1. Тепер потрібно підписати сертифікат server. Спочатку скопіюй файл server.req для ЦС. Заміни ВАШ_КОРИСТУВАЧ на свого користувача:

scp /home/ВАШ_КОРИСТУВАЧ/easy-rsa/pki/reqs/server.req /tmp

2. Підпиши запит скриптом easyrsa, використовуючи опцію sign-req і тип запиту server:

./easyrsa sign-req server server

3. Введи yes, а потім пароль ЦС, який ти створив на початку. Нагадаємо, що це pass:

pass

4. Скопіюй сертифікат сервера server.crt та сертифікат ЦС ca.crt до директорії /tmp:

scp pki/issued/server.crt /tmp
scp pki/ca.crt /tmp

5. Скопіюй ці файли з /tmp до /etc/openvpn/server:

sudo cp /tmp/{server.crt,ca.crt} /etc/openvpn/server

Криптографія OpenVPN

1. Щоб підвищити рівень безпеки, додамо ще один секретний ключ, спільний для сервера і клієнтів, за допомогою OpenVPN tls-crypt. Створи його:

cd ~/easy-rsa
sudo apt update
sudo apt install libpkcs11-helper1
sudo apt install openvpn
openvpn --genkey --secret ta.key
У новіших версіях OpenVPN (2.5 і вище) команда має вигляд openvpn --genkey secret ta.key.

2. Скопіюй файл ta.key до каталогу /etc/openvpn/server/:

sudo cp ta.key /etc/openvpn/server

Тепер можна створювати сертифікати клієнтів твого VPN та ключі для підключення до OpenVPN.

Генерація сертифікатів та ключів клієнтів

1. Створи директорії для сертифікатів і ключів клієнтів та признач їм права:

mkdir -p ~/clients/keys
chmod -R 700 ~/clients

2. Запусти скрипт easyrsa з опціями gen-req і nopass, вказавши CN клієнта. Зверни увагу: друга команда починається саме з ./easyrsa. Якщо пропустити ./, отримаєш помилку.

cd ~/easy-rsa
./easyrsa gen-req client-1 nopass

Система запропонує ввести Common Name. Прийми ім'я за замовчуванням, натиснувши Enter:

3. Скопіюй client-1.key до ~/clients/keys/:

cp pki/private/client-1.key ~/clients/keys/

4. Скопіюй файл client-1.req для ЦС:

scp pki/reqs/client-1.req /tmp

5. Підпиши цей запит, використовуючи тип запиту client:

cd ~/easy-rsa
./easyrsa sign-req client client-1

6. Введи yes, а потім пароль ЦС. Нагадаємо, що це pass:

pass

7. Так згенеровано сертифікат клієнта client-1.crt. Перемісти його в директорію /tmp і скопіюй до ~/clients/keys/:

scp pki/issued/client-1.crt /tmp
cp /tmp/client-1.crt ~/clients/keys/

8. Скопіюй ca.crt та ta.key до каталогу ~/clients/keys/ і встанови відповідного власника. Заміни ВАШ_КОРИСТУВАЧ на свого користувача двічі, наприклад user036:user036:

cp ~/easy-rsa/ta.key ~/clients/keys/
sudo cp /etc/openvpn/server/ca.crt ~/clients/keys/
sudo chown ВАШ_КОРИСТУВАЧ:ВАШ_КОРИСТУВАЧ ~/clients/keys/*
