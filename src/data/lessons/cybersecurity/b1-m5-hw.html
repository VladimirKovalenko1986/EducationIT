Настав час практики!

Сьогодні ти:

  • отримаєш навички проєктування архітектури кібербезпеки для компаній, що спеціалізуються на фінансових послугах;
  • відпрацюєш навички вибору й обґрунтування систем кібербезпеки, таких як XDR, антивірус, DLP та SIEM;
  • ознайомишся з процесами, які ці системи автоматизують, і з тим, як вони співпрацюють, щоб повноцінно захищати інформаційні ресурси компанії.

Завдання (крок за кроком)

1. Референтна архітектура

Ознайомся з референтною архітектурою кібербезпеки Microsoft Cybersecurity Reference Architectures (MCRA).

2. Концепція архітектури

Створи концепцію архітектури кібербезпеки для уявної компанії, що спеціалізується на фінансових послугах.

3. Вибір систем кібербезпеки

Вибери й обґрунтуй використання систем кібербезпеки: XDR, антивірус, DLP та SIEM.

4. Автоматизація та взаємодія

Опиши процеси, які ці системи автоматизують, і поясни, як вони співпрацюють між собою, щоб повноцінно захищати інформаційні ресурси компанії.

Підказки. Опис систем є в темі «Екосистема кібербезпеки», а приклад аналізу за MCRA — у кейсі теми «Референтні архітектури кібербезпеки».

Формат здачі

Документ на Google Docs із розшареним доступом. Надай опис концепції разом з обґрунтуванням вибору систем кібербезпеки та поясненням їхньої взаємодії. Додай пояснення, як референтна архітектура кібербезпеки допомагає впроваджувати та оптимізувати твою концепцію.

Критерії прийняття завдання

  1. Чітка та обґрунтована концепція архітектури кібербезпеки.
  2. Обґрунтування вибору та використання систем кібербезпеки.
  3. Пояснення процесів автоматизації та взаємодії між обраними системами.
  4. Розуміння та застосування референтної архітектури кібербезпеки для оптимізації концепції.
