Яка головна функція Security Operations Center (SOC)?

  • Розробка нового програмного забезпечення для компанії
  • Цілодобовий моніторинг, виявлення та реагування на кіберінциденти
  • Закупівля мережевого обладнання
  • Навчання користувачів роботі з офісними програмами

Що з переліченого належить до тріади CIA?

  • Конфіденційність, цілісність, доступність
  • Контроль, ідентифікація, аудит
  • Шифрування, автентифікація, авторизація
  • Моніторинг, реагування, відновлення

На якому рівні моделі OSI працює протокол IP?

  • Канальному
  • Транспортному
  • Мережевому
  • Прикладному

Скільки біт має адреса IPv6?

  • 32
  • 64

  • 128

Яка команда в Linux змінює права доступу до файлу?

  • chown
  • chmod
  • ls -l
  • passwd

Що таке фішинг?

  • Атака, під час якої зловмисник видає себе за довірене джерело, щоб виманити дані або змусити виконати дію
  • Перевантаження сервера великою кількістю запитів
  • Шифрування файлів з вимогою викупу
  • Пошук відкритих портів у мережі

Чим асиметричне шифрування відрізняється від симетричного?

  • Воно працює лише з текстовими файлами
  • Для шифрування і розшифрування використовується той самий ключ
  • Використовується пара ключів: відкритий для шифрування і закритий для розшифрування
  • Воно не потребує ключів

Що з переліченого є індикатором компрометації (IOC)?

  • Політика паролів компанії
  • Хеш шкідливого файлу або IP-адреса командного сервера
  • Графік резервного копіювання
  • Список працівників відділу безпеки

Згідно з моделлю спільної відповідальності в хмарі, за що відповідає клієнт AWS?

  • За фізичну охорону центрів обробки даних
  • За обладнання серверів і мережі AWS
  • За свої дані, облікові записи та налаштування доступу
  • За електроживлення та охолодження

Яку дію виконує правило фаєрвола з дією Block у pfSense?

  • Мовчки відкидає пакети, що підпадають під правило
  • Відкидає пакети й надсилає відправнику повідомлення про відмову
  • Пропускає пакети й записує їх у журнал
  • Перенаправляє пакети на інший сервер
