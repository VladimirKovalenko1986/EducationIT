Переходимо до виконання домашнього завдання!

Це перший крок до твого власного сайту для портфоліо — WebStudio. У цьому завданні ти зверстаєш HTML-розмітку сторінки за макетом, поки що без CSS-оформлення.

Порядок дій описано в темі «Алгоритм створення сторінки». Дотримуйся його — так ти не пропустиш важливих кроків.

Завдання

  1. Створи репозиторій goit-markup-hw-01.
  2. Зверстай HTML-розмітку макета сторінки домашнього завдання #1, без CSS-оформлення.
  3. Налаштуй GitHub Pages і додай посилання на живу сторінку в розділ About репозиторію на GitHub.
Як налаштувати GitHub Pages. У репозиторії відкрий Settings → Pages, у полі Source вибери Deploy from a branch, гілку main і папку / (root), натисни Save. За кілька хвилин сторінка з'явиться за адресою https://твій-логін.github.io/goit-markup-hw-01/. Щоб додати її в розділ About, натисни на шестерню біля About на головній сторінці репозиторію й встав посилання в поле Website.

Критерії прийняття завдання

Ось на що звертатиме увагу ментор.

Проєкт

  • A1. HTML-файл називається index.html.
  • A2. У корені проєкту є папка images із зображеннями.
  • A3. У назвах файлів немає великих літер, кирилиці, пробілів і трансліту — лише англійські літери й слова.
  • A4. Код відформатовано за допомогою Prettier.
  • A5. Усі зображення та текстовий контент узято з макета.
  • A6. Усі растрові зображення оптимізовано за допомогою Squoosh.
  • A7. Код написано відповідно до настанов Code Guide.

Розмітка

  • B1. Розмітку набрано у файлі index.html.
  • B2. Зверстано HTML-розмітку всіх елементів макета.
  • B3. Теги використано відповідно до їхнього семантичного змісту.
  • B4. HTML проходить перевірку валідатором без помилок.
  • B5. Основну структуру сторінки виділено тегами <header>, <main> і <footer>.
  • B6. Логотип у хедері та футері — це посилання з текстом, а не зображення.
  • B7. Тег <nav> використано на сторінці один раз — у хедері.
  • B8. Контакти в хедері (пошта й телефон) розміщено поза тегом <nav>.
  • B9. Тег <h1> використано на сторінці один раз.
  • B10. Елемент з текстом Order Service — це кнопка з атрибутом type="button".
  • B11. Заголовки секцій розмічено тегом <h2>.
  • B12. У тегів <img> вказано атрибути розмірів — щонайменше width.
  • B13. У тегів <img> є атрибут alt з коротким описом того, що зображено. Опис написано тією ж мовою, що й решта тексту сторінки.
  • B14. Зображення експортовано з макета у форматі JPG.
  • B15. Групи однотипних елементів зібрано у списки <ul>.

Формат здачі

Посилання на репозиторій goit-markup-hw-01 на GitHub і посилання на живу сторінку в GitHub Pages.
